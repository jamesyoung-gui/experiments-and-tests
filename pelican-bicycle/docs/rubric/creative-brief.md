# 创意简报（仅供构建者与导演）

> 以下创意示例原先写在锚点里，v2 移到这里：只给构建者与导演看，维度评审与盲评都拿不到。照搬这里的示例不获得任何"新颖"分；新颖与惊喜只由盲评判断。

- 故事循环示例 "The Fish Run"：巡航 → 一只鸥滑翔而来往车筐丢下一条沙丁鱼，鹈鹕 double take → 摇铃致谢 → 跳过一只横穿马路的螃蟹 → 抛鱼、头朝前接住、吞下，隆起沿颈下行 → 骄傲地抖羽 → 回到巡航，车筐鱼数守恒。（注意 v2 的节拍上限：24 s 内 ≤5 个主要节拍。）
- 开场钩子示例：车铃镀铬反光的特写，拇指一弹，反光光圈展开成全景，鹈鹕骑入、看一眼镜头出发。
- 标志性时刻候选：拖动时间精确倒放（鹈鹕把鱼"吐"回车筐、鸥倒着飞）；画面一笔一笔变形成它自己的工程蓝图；实时 JS 与零 JS 烘焙 SVG 的分屏擦除并显示 Δ%。注意：倒放擦洗本身是熟悉的视频播放器效果，属于 C8.1 的 5 分档。
- 彩蛋示例：Gimini 式"Velocipedia"错误自行车广告牌；"加州褐鹈鹕繁殖羽"物种切换；长按车铃奏《茉莉花》（公有领域）；夜空中的"鹈鹕骑车"星座；夜里偷鱼的鸥被车灯照亮。
- 面部表演示例：挥手时 3/4 视角看镜头眨一下眼；灯塔光束扫过时眯眼；被冷落时把冠羽像眉毛一样挑起。
- 配角示例：一队大白鹈鹕以逐只扑翼相位延迟低掠海面（Weimerskirch et al. 2001, Nature 的编队飞行研究用的就是这个物种）。
- 风格 C 细节灵感：港镇的钟楼与晾衣绳、车票式的"鹈鹕湾—灯塔 · 单程"注记、邮戳上的日期、套印色标条、浮标编号、帆船上的信号旗。
