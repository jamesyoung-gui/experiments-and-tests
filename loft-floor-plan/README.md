# Loft floor plan · 三层平面图（健身房 + 书房）

用纯代码画的平面图，不依赖任何第三方库（只用到 Python 3 标准库）。几何尺寸按原施工图纸《三层平面图》数字化，
图纸上的铅笔修改也一并画进去了。

```bash
python3 floor_plan.py     # 生成 base.svg / current.svg / proposed.svg
```

| 文件 | 内容 |
| --- | --- |
| `floor_plan.py` | 墙、柱、门窗、房间和家具都写成毫米坐标数据，渲染成 SVG |
| `base.svg` / `.png` | 原图纸 + 铅笔修改（红色 = 划掉，橙色 = 新增） |
| `current.svg` / `.png` | 现状：按铅笔修改后的格局，家具位置按现场照片还原 |
| `proposed.svg` / `.png` | 规划：上半区健身、西北窗区做有氧、下半区书房和影音、储藏间改恢复室 |

## 图纸上的铅笔修改

1. 前室（电梯 / 楼梯口）北端新开一扇门，作为进大厅的入户门
2. 前室西侧的隔墙向上延长到这扇新门，把前室封起来
3. 原来靠南墙的那扇前室门封掉
4. 前室里那组横向柜子取消（竖向的玄关柜保留）

## 空间要点（按图纸）

- 整层 14.4 m × 11.6 m（含阳台）。大厅是 L 形，净面积约 74 ㎡；算上卫生间、储藏间、前室、电梯和楼梯，约 125 ㎡
- 图纸上方：北墙，两段长窗
- 图纸左侧：落地玻璃和阳台对开门，外面是 L 形阳台（约 29 ㎡）
- 西北角：凹进去的窗区，外面是空调平台
- 右侧：卫生间（淋浴、浴缸、马桶间）、过道、储藏间、前室、电梯和楼梯
- 水吧在卫生间西墙边（图纸上那里画的是一组高柜），固定，不可改动

> 现状图里家具的位置是根据照片估的，门窗和墙体都按图纸尺寸画。
