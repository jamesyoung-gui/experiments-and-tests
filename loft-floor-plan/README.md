# Loft floor plan · 三层平面图（吧台 + 工作 + Lounge）

用纯代码画的平面图，不依赖任何第三方库（只用到 Python 3 标准库）。建筑尺寸按原施工图纸《三层平面图》数字化，
图纸上的铅笔修改也画进去了。出图时统一转成**上北下南左西右东**：原图纸是横着画的，这里逆时针转了 90°。

```bash
python3 floor_plan.py     # 生成 base.svg / proposed.svg
```

| 文件 | 内容 |
| --- | --- |
| `floor_plan.py` | 建筑数据用图纸坐标（`DRAWING_*`），家具用转正后的平面坐标，渲染成 SVG |
| `base.svg` / `.png` | 原图纸 + 铅笔修改（红色 = 划掉，橙色 = 新增） |
| `proposed.svg` / `.png` | 新规划：吧台 + 大桌办公 + lounge（健身器材全部搬走） |

## 空间（上北下南）

- 南：L 形大阳台（约 29 ㎡），东半区南墙有阳台对开门
- 西：两段长窗；西翼南端是一个带南窗的窗区
- 东：两扇窗（原来佛龛在两窗之间，佛龛会搬走）
- 北：卫生间、储藏间（保留）、前室、电梯、楼梯
- 大厅是 L 形，净面积约 74 ㎡；整层约 125 ㎡

## 铅笔修改

1. 前室西端新开入户门，从前室直接进大厅
2. 前室隔墙延长到这扇门
3. 原来靠东墙的前室门封掉
4. 前室里的横向柜子取消，玄关柜保留

## 规划思路

- **吧台（日咖夜酒）**：一进门就是。后吧台沿用现有水吧的上下水（咖啡机 · 水槽 · 半高饮料柜）。
  半岛吧台 3.1 × 0.95 m 抵着西墙，配 4 张吧凳；后吧台和半岛之间留 1 m 的操作通道
- **Lounge**：西翼中南段。三人沙发背对吧台，面向南端窗区，茶几在前，两把单人椅分在两侧，铺一整块地毯。
  窗区放绿植和窗下矮柜（黑胶 / 书）
- **工作区**：东半区，放一张 3.0 × 1.2 m 的实木大桌，人背靠东窗、面向整个大厅，阳台的光从侧面进来。
  55" 架高电视放在桌前当显示器，屏幕后面是开敞空间，不会逆光。
  一对 JBL 4329P 上落地架，放在电视两侧，和座位大致构成听音三角，位置可以随时挪
- 前室隔墙在大厅一侧做一整面开放书架，东窗下放矮柜，收打印机和文件
