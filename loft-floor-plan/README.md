# Loft floor plan · 小洋楼三层（吧台 + Deep work + Lounge）

用纯代码画的平面图，不依赖任何第三方库（只用到 Python 3 标准库）。建筑尺寸按原施工图纸《三层平面图》数字化，
图纸上的铅笔修改也画进去了。出图时统一转成**上北下南左西右东**：原图纸是横着画的，这里逆时针转了 90°。

```bash
python3 floor_plan.py     # 生成 base / plan_a / plan_b / bar_options / entry_detail 五张 SVG
```

| 文件 | 内容 |
| --- | --- |
| `floor_plan.py` | 建筑数据用图纸坐标（`DRAWING_*`），家具用转正后的平面坐标，渲染成 SVG |
| `base.svg` / `.png` | 原图纸 + 铅笔修改（红色 = 划掉，橙色 = 新增） |
| `plan_a.svg` / `.png` | 方案 A（推荐）：门槛区先压后放 → 靠墙大 L 吧台；东半区客厅（东墙整面影音墙、大 L 沙发、东南角单人椅）；西窗坐榻；西翼南端 deep work |
| `plan_b.svg` / `.png` | 方案 B：西翼新加一道电视墙隔开吧台和 lounge，东半区做工作室 |
| `entry_detail.svg` / `.png` | 入口前后对比：鞋柜和玄关在 1 楼，3 楼的门不动；门外状态灯 + 挂画，门内 1 m 门槛区换材质、吊顶压低，视线尽头是吧台转角 |
| `bar_options.svg` / `.png` | 吧台三种做法：① 靠墙大 L（推荐），② 后吧台 + L 形前台，③ 平行式 |

## 定位

- 1 楼是公用餐厅；2 楼是起居（厨房、餐厅、卧室、电视）。爸妈白天来公司时会在 2 楼吃午饭、午睡
- 办公室在 20 m 外，健身房、接待和会议都在那边。董事长办公室是和爸爸共用的
- 所以 3 楼是唯一完全私人的空间：白天一个人 deep work（Claude Code），晚上和女朋友日咖夜酒、听音乐，
  偶尔约朋友。公司的人不会上来
- 音乐从电脑 / 手机推流到一对 JBL 4329P（有源）。4329P 跟客厅的大电视放在一起；
  原来的 55" 电视搬去董事长办公室，书桌换一台 32" 高分屏显示器
- 储藏间保持原样，佛龛搬走
- 真正的玄关和鞋柜在 1 楼入口，3 楼这扇门是家里面的门，门本身不动

## 入口

前室是电梯和楼梯开门的公共楼道，所以门内单独做一个约 1.3 × 1.5 m 的玄关：
- 正对门放一组双面顶天高柜当屏风。朝玄关那面放鞋、外套和包，背面朝吧台做酒架 / 杯架
- 门边那段储藏间外墙挂镜子，下面放钥匙台，地面换成石材落尘区，旁边放一张换鞋凳
- 高柜北侧留 0.9 m 宽的通道去吧台和卫生间（进门先洗手），南侧去客厅

门外的前室整栋楼只有自家用，当电梯厅来做，从公共到私人分三段过渡：
- 楼梯口换地面材质（楼梯保留地砖，前室起换成木地板或微水泥），这条线就是公私分界
- 原来的玄关柜改成悬空矮柜（放快递、雨伞），上方挂画配壁灯，出电梯正对的就是这一面
- 电梯改 3F 刷卡，1 楼公共餐厅的人上不来；入户门换智能锁

## 空间（上北下南）

- 南：L 形大阳台（约 29 ㎡），东半区南墙有阳台对开门
- 西：五扇约 0.6 m 宽的窄窗（北三南二），窗间是实墙；西翼南端有三扇窄窗
- 东：四扇窄窗，两两一组（原佛龛在两组之间）
- 只有朝南阳台那面是落地玻璃 + 对开门
- 北：卫生间、储藏间、前室、电梯、楼梯。现有小水吧贴着卫生间南墙，吧台都从这里的上下水长出来
- 大厅是 L 形，净面积约 74 ㎡

> 西墙的窗台高度要现场量一下。吧台方案 ① 和 ③ 都有一段台面贴着西窗下沿，窗台低于 0.9 m 的话要调整。

## 方案 A 评审记录

请一个独立评审代理按“平衡、舒适、动线、入口序列”做了两轮评审，按意见修改：

- 第一轮 5.5 / 10：圆桌堵住调酒台、玄关凳子挡鞋柜、电视压窗、单人椅没法坐、书架和书桌错位。
  已改：两人小圆桌；玄关重组；东墙电视背景板；书架单面朝北并和书桌对齐；沙发缩短并加背几；前室矮柜改 250 深；阳台加躺椅。
- 第二轮 6.8 / 10：玄关通道在有人换鞋时只剩 0.68 m、外侧两扇东窗被音箱挡住、客厅重心偏西北、大绿植卡在主动线上。
  已改：壁挂凳缩到 350 深并东移，鞋柜南移，玄关通道恒定 1.2 m；东墙改整面影音墙（外侧窗留洞 + 双层卷帘），
  北音箱反射点贴吸声板；单人椅回到客厅东南角；西窗改嵌入坐榻；大绿植移到客厅东南角；吧台转角留空做门的视线尽头；
  南面玻璃全宽遮光帘；空调外机放平台东端并做减振隔声。
