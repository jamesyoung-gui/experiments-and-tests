# Loft floor plan · 工厂楼上大平层（健身房 + 书房）

用纯代码画的平面图，不依赖任何第三方库（只用到 Python 3 标准库）。

```bash
python3 floor_plan.py     # 生成 current.svg 和 proposed.svg
```

| 文件 | 内容 |
| --- | --- |
| `floor_plan.py` | 空间、墙、窗、门和家具都写成坐标数据，渲染成 SVG |
| `current.svg` / `.png` | 现状：根据 4 张现场照片还原 |
| `proposed.svg` / `.png` | 规划：Gemini 对话里最后定下的方案（东侧健身、西侧书房和影音、中间留白） |

## 空间要点

- 大厅约 13 m × 10 m ≈ 130 ㎡，层高约 3.5 m，井字格吊顶（图里的虚线）
- 北侧：整面落地窗和阳台对开门，外面是约 20 ㎡ 的阳台
- 东墙：三扇竖长窗
- 西墙：两扇纱帘窗（原来放佛龛和书桌的位置）
- 南侧：书架墙、入口、卫生间和储藏凹位，东南角是水吧（固定，不可改动）

## 规划要点

- **健身区（东）**：2 cm 黑色橡胶地垫；不锈钢史密斯三合一靠东墙；SkiErg、划船机朝窗放；哑铃架；
  留出 3 m × 3.4 m 的空地练脚步和增强式训练；镜子做成可移动的，兼作拍摄机位
- **书房和影音区（西）**：顶天立地的书墙；岛式升降桌（1" 薄桌面），坐的时候背靠书墙；
  Maralunga 沙发背靠阳台；LG C5 装在移动支架上，底下挂 Soundbar，办公位和观影位之间原地转向；
  低音炮放在沙发旁边
- **小房间**：改成恢复室（放按摩床，或者用来冥想、午睡）

> 尺寸和入口、卫生间、储藏室的位置都是根据照片目测推断的。量好实际尺寸后，
> 改 `floor_plan.py` 顶部的常量（`ROOM_W`、`ROOM_D`、`OPENINGS`、`ANNEXES`）再重新生成就行。
